### PropAMM Contract Interface Mismatch Compared to Ethereum

### Question
Are the Priority Update Registry and Swap contract interfaces for PropAMM on BSC compatible with the Ethereum interfaces?

### Answer
No, the Priority Update Registry and Swap contract interfaces on BNB Smart Chain (BSC) do not match the interfaces used on Ethereum. 

BSC does not support the Ethereum-native interfaces for PropAMM. If you are migrating from Ethereum to BSC, you must:
1.  **Adjust Contracts**: Modify your contracts to align with the BSC-specific PropAMM interfaces.
2.  **Audit Adjusted Contracts**: Conduct new audits for the adjusted contracts to ensure security and compatibility with the BSC implementation.

Developers can use the official PropAMM dashboard on BSC to monitor activity and performance.
