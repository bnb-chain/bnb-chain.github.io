### When is the deadline for the BSC v1.8.2 mainnet Jenner hardfork upgrade?

The BSC Mainnet Jenner hardfork is scheduled for **December 8, 2026, at 02:30:00 UTC** (Unix timestamp `1796697000`).

This is a **mandatory upgrade** for all BSC Mainnet node operators, MEV builders, and sentry operators.

### Upgrade requirements
- Replace the binary with **v1.8.2** and restart your node **before the activation time**. Upgrade in advance so you can check that the node is running correctly before activation.
- If upgrading from v1.7.x or v1.8.0-alpha, review the [v1.8.0-alpha notes](https://github.com/bnb-chain/bsc/releases/tag/v1.8.0-alpha) and [v1.8.1 notes](https://github.com/bnb-chain/bsc/releases/tag/v1.8.1) for removed configuration fields, RPC changes, and MEV gRPC settings. These non-consensus changes can take effect before the hardfork.

### Official reference
See the [BSC v1.8.2 release notes](https://github.com/bnb-chain/bsc/releases/tag/v1.8.2) for the activation schedule and upgrade procedure.
