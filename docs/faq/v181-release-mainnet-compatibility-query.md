### v1.8.1 Release Mainnet Compatibility Query

### Question
Do BSC mainnet nodes need to upgrade to v1.8.1 for the Jenner hardfork?

### Answer
No. **BSC v1.8.1 is the Chapel testnet Jenner hardfork release.** BSC mainnet nodes do not need to upgrade to this release for Jenner.

The official release targets Chapel testnet node operators, MEV builders, and sentry operators. Chapel testnet activation is scheduled for **October 29, 2026 at 02:30 UTC**. Mainnet activation is not scheduled in this release.

Mainnet operators should follow the currently recommended mainnet release and wait for a separate official mainnet Jenner upgrade notice. Do not infer a mainnet activation date or required version from the testnet release.

Source: [BSC v1.8.1 release notes](https://github.com/bnb-chain/bsc/releases/tag/v1.8.1).
