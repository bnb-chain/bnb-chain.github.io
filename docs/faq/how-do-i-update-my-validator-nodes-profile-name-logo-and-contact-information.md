### How do I update my validator node's profile name, logo, and contact information?

### Problem
How to update a validator's display name, logo, description, and contact details on the BSC staking portal.

### Solution
To update your validator's profile information, you must submit a Pull Request (PR) to the official validator directory repository on GitHub:

1. Go to the [bnb-chain/bsc-validator-directory](https://github.com/bnb-chain/bsc-validator-directory) repository.
2. Follow the repository's contribution guidelines to update your validator's metadata (e.g., modifying the JSON information or uploading a new logo file).
3. Submit a Pull Request with your proposed changes.
4. Once the PR is reviewed and merged by the BNB Chain team, the updated information will be reflected on the staking webpage.
