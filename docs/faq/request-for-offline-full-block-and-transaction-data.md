### Request for offline full block and transaction data

### Question
How can I access historical BSC block and transaction data for offline analysis?

### Answer
The [BSC snapshots repository](https://github.com/bnb-chain/bsc-snapshots) lists node snapshots, including historical block files split by year. Review the snapshot descriptions and usage instructions to select the data and node configuration you need. These are node data snapshots, not necessarily a ready-to-use analytical dataset.

For indexed data, you can also use a third-party analytics platform such as [Dune](https://dune.com/), subject to its coverage and export limits. If you need historical state as well as block data, see the [BSC archive node guide](https://docs.bnbchain.org/bnb-smart-chain/developers/node_operators/archive_node/).
