# Quick Guide - BNB Smart Chain (BSC)

Quick guide for BSC developers. BSC is EVM-compatible, so existing Ethereum smart contract skills transfer.

- Connecting: network information, RPC providers, wallet configuration.
- Tokens: BSC testnet faucet; mainnet CEX withdrawal.
- JSON-RPC API: Geth-compatible JSON-RPC methods.
- Official Developer Kit: SDK cards, MCP, Ask AI.
- Developer tools: explorers, SDKs, wallets, oracles, account abstraction, storage, and data analytics.
