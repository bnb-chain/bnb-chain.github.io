# Faucet

To develop and test on BNB Smart Chain testnet, you need test BNB (tBNB). The following faucets provide free testnet tokens.

## Official BNB Chain Faucet

The primary faucet for BSC testnet tokens, supporting tBNB and other major test tokens (USDC, BUSD, DAI):

- [BNB Chain Testnet Faucet](https://www.bnbchain.org/en/testnet-faucet)

## QuickNode Faucet

An alternative faucet provided by QuickNode:

- [QuickNode BSC Faucet](https://faucet.quicknode.com/binance-smart-chain/bnb-testnet)

## opBNB and Greenfield Testnet Tokens

- **opBNB:** Obtain tBNB on BSC testnet first, then bridge to opBNB using the [testnet bridge](https://opbnb-testnet-bridge.bnbchain.org). See the [opBNB faucet guide](../../bnb-opbnb/developers/network-faucet.md) for details.
- **Greenfield:** See the [Greenfield test BNB guide](../../bnb-greenfield/getting-started/get-test-bnb.md).
